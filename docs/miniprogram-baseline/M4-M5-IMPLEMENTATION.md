# 同页剪辑与两个转换模块

日期：2026-10-22。基于已同步主分支的 `feature/wechat-miniprogram`。用户已确认上一版本视频生成在真机部分格式可用；本次不将该反馈扩展为新裁剪/所有编码的实机验收。

## 交付内容

1. 视频页增加起点、终点、片段播放和恢复整段，移除打开系统剪辑器的步骤。封面限制在片段内，生成时裁剪，写入相对于片段起点的封面时间。
2. 本机 MP4/MOV 快速裁剪支持常见 H.264/HEVC 视频与 AAC 音频、B 帧、32/64 位偏移和常见单段编辑时间线。保留必要解码前置帧，重建样本表、偏移和播放时长。分片 MP4、混合样本描述、多段/变速编辑、无效轨道明确报错。
3. 照片 + 视频页复用视频片段控件；原始 JPEG 保留，PNG/设备可解码图片转为 JPEG，支持方向处理、透明铺白和居中裁切到视频比例。该模式无需取视频帧。
4. 批量页支持相册原图/聊天文件、多项选择、顺序处理、独立错误、暂停继续、重试、移除、单项/全部保存和原文件导出。保存被拒绝时停止后续权限请求，保留未保存状态并允许重试。
5. 共享核心加入内嵌媒体定位，落盘后继续回读校验；输入上限 60 MiB，输出视频 20 MiB、封面 8 MiB。

## 已执行测试

- 设置 `FFMPEG_EXE` 后运行 `node --test miniprogram/tests/*.test.cjs`：44 项通过，0 失败、0 跳过。
- 真实媒体用例生成 H.264 / HEVC + AAC / B 帧样本，分别裁剪整秒与非整秒区间；完整 FFmpeg 解码通过，输出首帧与原片所选起点像素一致。
- 真实 JPEG + 视频合成、裁剪后的 Motion Photo、再次批量转换、MOV 重封装通过格式校验；裁剪 1.25–3.5 秒时输出 2.25 秒，1.75 秒封面对应 XMP 500000 微秒。
- 合成 HEIC/mpvd 用例验证提取、调用设备 JPEG 归一化与中间文件清理；实际设备 HEIC 解码仍依赖微信能力。
- 批量页面用例覆盖有效/无效文件混合、去重、仅重试失败项、保留已成功输出、相册拒绝/重试和页面卸载清理。
- 微信开发者工具已重新编译，检查首页三入口、照片模式/批量页空态；实际选择本地 JPEG 后照片预览正常，未发现页面脚本错误。工具仍提示其自身预加载/Worker 调试警告。

以上真实媒体测试使用 Node 文件系统适配与桌面 FFmpeg，不是微信硬件解码或三星相册播放测试。新同页裁剪、HEIC、批量相册保存和照片方向/裁切仍应在目标真机回归。

## 复现

```powershell
node miniprogram/scripts/build-core.cjs --check
$env:FFMPEG_EXE = 'C:\path\to\ffmpeg.exe'
node --test miniprogram/tests/*.test.cjs
npm.cmd --prefix web test
npm.cmd --prefix web run build
```

微信开发者工具编译器 `wcc.exe` / `wcsc.exe` 用于检查四个页面、图标组件及样式。测试/脚本目录不进入小程序上传包。临时媒体样本保存在被忽略的 `tmp/` 或测试临时目录，不提交到仓库。
